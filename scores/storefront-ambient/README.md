# Storefront, ambient

The starter score that ships in the composer. D ionian, 66 bpm.

| Voice | Driven by | You should hear |
|---|---|---|
| Bass loop (acoustic bass) | traffic → density, log curve | Quiet: only the downbeats. Busy: the whole written line |
| Pad (warm pad, held chord) | errors → tension, exp curve | Clean: a consonant chord. Errors climbing: a sharp tone creeps in above the root and the chord drifts sharp |
| Pad | traffic below 12 for 20 s → minor | A slow night turns the chord minor; it lifts again once traffic is above 16 for 5 s |
| Surge motif (flute) | traffic slope above 40/min → trigger | A rising six-note flute phrase on the next bar when traffic climbs fast; at most once a minute |

Regenerate the file from the code: `pnpm exec tsx scripts/export-score.ts`.
